# Animal Farm Management System

## Overview
The Animal Farm Management System is a Java Swing desktop application built to help farms manage livestock records digitally. Users can register animals, track RFID information, update feeding schedules, log health records, and generate reports.

## Features
- Animal registration system
- RFID tracking
- Feeding logs
- Health alerts
- Reports dashboard
- Role-based access

## Built With
- Java
- Swing GUI
- File Handling
- OOP Concepts

## Challenges Solved
During development, I fixed bugs related to data saving, user input validation, and interface responsiveness. I also improved project organization and testing.
